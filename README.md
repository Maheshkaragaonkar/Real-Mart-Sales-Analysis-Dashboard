📊 Real Mart Sales Analysis Dashboard
📌 Project Overview

This project focuses on analyzing retail sales data to understand revenue, profit, and customer behavior. The goal is to provide meaningful insights through interactive dashboards using Excel, SQL, and Power BI to support business decision-making.

🎯 Objectives

Analyze overall sales and profit performance.

Identify top-performing products and categories.

Track monthly and yearly sales trends.

Understand customer purchasing patterns.

Support management with data-driven insights.

🛠️ Tools & Technologies

MS Excel – Data cleaning, preprocessing, pivot tables

SQL (MySQL) – Data extraction and querying

Power BI – Interactive dashboards and visualization

Python (Optional) – Data analysis using Pandas & NumPy

📂 Dataset

The dataset contains information such as:

Order ID

Customer Name

Product Category

Sales Amount

Profit

Quantity Sold

Order Date

Region

(Data used is for educational and practice purposes.)

📈 Dashboard Features

Total Sales, Total Profit, and Quantity KPIs

Monthly and Yearly Sales Trends

Top Products and Categories

Regional Performance Analysis

Interactive Filters (Slicers)

🔍 Key Insights

Identified high-revenue and high-profit products.

Detected seasonal sales patterns.

Highlighted underperforming regions.

Helped in optimizing inventory and marketing strategies.

🚀 Project Workflow

Collected and imported raw data.

Cleaned and formatted data in Excel.

Created SQL queries for analysis.

Built data model in Power BI.

Designed interactive dashboards.

Generated business insights.
